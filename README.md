# zomato-delivery-analysis
Кейс по очистке, преобразовании и визуализации данных на основе данных международного агрегатора ресторанов и сервиса по доставке еды, созданный в Индии - Zomato.

Работа, проделанная над данным датасетом:
1) удаление избыточных столбцов
2) переименование столбцов
3) убраны лишние пробелы
4) поиск и удаление дубликатов
5) приведение данных к нужному типу
6) работа с пропусками
7) объединение редких категорий
8) визуализация данных: можно ли заказать доставку или нет, есть ли возможность забронировать столик или нет, связь возможности бронирования стола и рейтинга, лучшие локации для ресторана, связь между локацией и рейтингом и тд
